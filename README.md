# 🤖 Chat AI - Gemini Powered Chatbot

This is a chat application that enables interactive conversations with an AI chatbot. It uses the **Gemini API** from Google to generate responses, making the experience smart and conversational.

## 🌐 Live Demo

👉 [Click here to try it live](https://symphonious-lamington-c27c36.netlify.app/)

---

## ⚙️ Tech Stack

- ⚛️ **React.js** – Component-based UI
- 🎨 **Tailwind CSS** – Utility-first styling
- 🌐 **Axios** – HTTP requests to the Gemini API
- 🧠 **Google Gemini API** – AI-powered text generation
- 📄 **React Markdown** – Renders AI responses with markdown formatting

---

## 🚀 Features

- 📥 Ask any question in natural language
- 🤖 AI replies via Google Gemini Pro
- 📄 Answers rendered with markdown (e.g., bold, bullet points, code)
- 📱 Fully responsive UI
- 🎨 Clean and modern Tailwind design
